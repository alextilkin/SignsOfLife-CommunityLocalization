# Contributing

By opening a pull request or otherwise submitting to this repository, you
agree to [`LICENSE.md`](LICENSE.md).

In short:

- `english/` is Sweet Dog Studios reference text. Do not republish it.
- You keep copyright in your translation.
- Sweet Dog Studios LLC may use, edit, and ship that translation in
  *Signs of Life*.
- Players may install the pack and play.
- Nobody gets a license to reuse the writing in another game.

## How to translate

1. Read [`TRANSLATING.md`](TRANSLATING.md) for voice and markup.
2. Edit files under `locales/<code>/Config/`. Leave untranslated rows out so
   the game keeps English.
3. Do not copy `english/` into a locale folder.
4. Do not submit AI generated text.
5. Open a pull request.
