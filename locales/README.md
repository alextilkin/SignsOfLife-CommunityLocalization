# Locales

Each folder is a Signs of Life mod pack (`modinfo.json` + `Config/`). Empty
`[]` overlay files mean the language is open for translation, not that English
has been copied in.

`pt-BR` already has HUD and spoken-line overlays from the game repository.
Do not replace those strings with machine output.

Font mode (`baked` vs `runtime`) is in [`../languages.json`](../languages.json).
