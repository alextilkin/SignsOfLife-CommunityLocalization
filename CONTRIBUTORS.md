# Translation contributors

We aim to acknowledge people whose accepted community translations we use.
Contributors can choose a GitHub username, another public name, or no public
credit when submitting a pull request, and can later request a correction or
removal. We do not list private email addresses or legal names by default.

This list is maintained on a best-effort basis. Inclusion here does not promise
that a contribution will ship, and credit is not guaranteed in every pack or
game release. Names will be added as accepted work is used.
